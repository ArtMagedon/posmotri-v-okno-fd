# Посмотри в окно

**«Посмотри в окно»** — интерактивное веб-приложение, позволяющее находить и смотреть видео с видами различных городов в разное время суток. Пользователь может выбрать город, задать время суток, просмотреть подходящие видеоролики и переключаться между ними.

Проект выполнен в рамках обучения на курсе веб-разработки Яндекс Практикума.

## Функциональность

- Просмотр видео в главном видеоплеере.
- Поиск видео по названию города.
- Фильтрация видео по времени суток: утро, день, ночь.
- Комбинирование поисковых параметров.
- Переключение видео при выборе карточки из списка.
- Отображение информации о городе и видео в карточках.
- Пагинация с возможностью загрузки дополнительных карточек.
- Прелоадеры во время загрузки данных и видео.
- Обработка ситуаций, когда подходящие видео отсутствуют или возникают ошибки при загрузке.
- Кастомный скроллбар списка видео.

## Технологии

- **HTML5** — структура страницы, формы, шаблоны карточек и видеоплеер.
- **CSS3** — оформление интерфейса, Flexbox, Grid, анимации, кастомные элементы управления и состояния интерактивных элементов.
- **JavaScript (ES6+)** — взаимодействие с DOM, обработка событий, асинхронные запросы, работа с Fetch API и генерация карточек на основе шаблонов.
- **Fetch API** — получение данных о видео с внешнего API.

## API

Для получения списка видео используется внешний API:

`https://v-content.ffapi.ru/api/videos`

Данные включают информацию о городах, описания видео, время суток, ссылки на видеоролики и превью.

## Запуск проекта

Проект не требует установки зависимостей или сборки.

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/ArtMagedon/posmotri-v-okno-fd.git
   ```

2. Перейдите в директорию проекта:

   ```bash
   cd posmotri-v-okno-fd
   ```

3. Запустите локальный веб-сервер, например, с помощью Python:

   ```bash
   python3 -m http.server 8000
   ```

4. Откройте приложение в браузере по адресу [http://localhost:8000](http://localhost:8000).

Также проект можно запустить с помощью расширения **Live Server** в Visual Studio Code.

> Для корректной работы приложения необходимо подключение к интернету, поскольку данные и видео загружаются с внешнего сервера.
